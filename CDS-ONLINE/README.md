# CONFLICT: DESERT STORM — browser assembly (plan-first rebuild)

The original game, assembled fresh from its own decoded files. BLACK DECADE
under `fidelity/` is untouched and remains the fallback (tag
`black-decade-final-v73`).

## Layout
- `PLAN.md` — the governing plan (P0–P7 + research tracks R1–R3).
- `game/` — the playable build: `index.html` + `frontend.js` (original
  frontend), `sim.js` (simulation: literal Catalog state-rule machines,
  ENV/HLOI worlds, Weaps/VStat combat, vehicles, doors/switches),
  `cdsfont.js` (original glyph renderer), `data/` (Catalog tables, decoded
  `.loc` strings, per-mission JSON), `vendor/` (Three.js).
- `tools/` — `pipeline.py` (P1 asset pipeline from the extracted archives),
  `envparse.py` (`.ENV` → mission JSON), `survivors.py` (converts the
  surviving fidelity mission data for archives still missing), 
  `bankrecover.py` (`.sch` bank names by elf_hash), probes
  (`p2probe.mjs`, `p34probe.mjs`, `p5probe.mjs`).

Binary assets (GLBs, sprite banks, WAVs) are regenerated by `tools/pipeline.py`
from the original `.dat` archives; they live in the sandbox checkout
(`game/assets/`, symlink `game/assets/models-survivors` → `fidelity/models`).
